# Mémoire du projet — à lire en premier

But : reprendre le projet sans relire tout l'historique. Lire ce fichier, puis `STATE.md`.

| Fichier | Contenu |
|---|---|
| `STATE.md` | Où on en est, prochaine action (mis à jour à chaque étape) |
| `DECISIONS.md` | Décisions prises et pourquoi (ne pas les rediscuter) |

Règle : tout agent qui termine une tâche met à jour `STATE.md` (1-3 lignes).

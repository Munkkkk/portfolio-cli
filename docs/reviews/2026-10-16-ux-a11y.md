## Important
1. **Bullets clipped at the left edge** - src/app/globals.css:27-31 (`* {padding:0;margin:0}` zeroes `ul` padding) + src/commands/*.tsx `<ul>` (help.tsx, experience.tsx, projects.tsx, skills.tsx, contact.tsx...).
   Repro: 375x812, run `help`, zoom on the left edge. `li` left = 16px (terminal padding) and `list-style-position: outside` puts the disc left of x=16; pixel scan of columns 0-29: bright pixels start at x=0 (229,229,229,222 then bg) so the disc is cut at the viewport edge, only ~4px visible. Same at 1280 (x=0 relative to the 16px padding box, i.e. markers in the gutter hugging the edge). Expected: full ~7px marker with margin.
   Fix: `.output ul { list-style-position: inside }` or `.output ul { padding-left: 1.5ch }` in Terminal.module.css.
2. **Links indistinguishable from text** (WCAG 1.4.1) - src/app/globals.css:33-36 (`a {color:inherit; text-decoration:none}`).
   Repro: `projects` / `contact`: `a` color rgb(229,231,235) = surrounding text color, no underline. Expected: non-color cue or 3:1 vs text.
   Fix: `.output a { color: var(--accent); text-decoration: underline; }`.

## Mineur
1. Input has no visible focus indicator (only caret; `outline:0`) - Terminal.module.css:77-86. Measured: Tab to input -> outlineStyle none. Fix: add `.promptRow:focus-within .promptLabel` style or a subtle underline/outline on `.input:focus-visible`.
2. Prompt sits flush with the viewport bottom: at 375x400 input bottom = 399.05 of 400 (1280x800: 799.3/800) - the `scroll-margin-bottom:16px` on .promptRow (Terminal.module.css:74) is ignored because scrollIntoView targets `endRef` (Terminal.tsx:29), which is the last child before the padding. Fix: scroll `inputRef`/promptRow into view, or give endRef `scroll-margin-bottom:16px`.
3. Mobile keyboard: no `viewport` export with `interactiveWidget` (layout.tsx); on Chrome Android default resizes visual viewport (prompt stayed visible in 400px emulation), iOS Safari not testable here. Fix: optional `export const viewport = { interactiveWidget: "resizes-content" }`.
4. Recruiter welcome: buttons are bare command names (`help`, `about`...) with no hint of what they do - Welcome.tsx:13-24. Fix: add a one-line "Click a command below or type it" or title/description per button.
5. `mailto:` link uses `target="_blank"` (contact.tsx) - opens blank tab on some browsers. Fix: drop target for mailto.
6. Terminal.module.css hard-codes #0b0f14/#e5e7eb duplicating globals.css vars (:7-8) - maintainability only.
